# 冷却水按温差自动调流、每模计量与自动停运

## 背景：原来怎么干活

冷却泵只有运行/停止两态，**流量恒定开着**，靠人盯：

- 模具厚薄不一样，进出口温差也不一样，但流量没法跟着变；
- 模具快冷透了，水还在满流量排走；
- 什么时候能停、这一模用了多少水，全靠经验和手抄。

本方案把"看温差调流量、算水量、判冷透停泵"交给冷却回路自动完成。

## 需要的现场仪表/执行器

| 用途 | 设备 | 说明 |
|------|------|------|
| 进水温度 | PT100/PT1000，进水管 | 已有则复用 |
| 出水温度 | PT100/PT1000，出水管 | 与进水同型号、做过配对 |
| 调流量 | 电动调节阀（4–20 mA / 0–10 V） | 加在冷却支管上，开度 0–100% 连续可调；推荐等百分比或线性阀 |
| 流量校核 | 电磁流量计（可选但建议） | 校核阀位折算流量、检测堵管/断流 |
| 模次信号 | 硫化机开模/计时完成信号 | 用作每一模冷却的起点 |

泵维持恒速运行（或变频恒压），**流量由调节阀控制**，泵不参与快速调节。

## 控制逻辑（`rubbercure/cool/`）

每个控制周期（建议 1 s）执行一次 `CoolingUnit.regulate(进水温, 出水温, dt)`：

1. **采样**进出口温度，算温差 `ΔT = 出水 − 进水`；
2. **温差 PI 闭环**（`flow.py`）输出调节阀开度：
   - `ΔT ≥ 目标温差`（模具还烫）→ 直接满阀冲流，先把温度压下来；
   - `ΔT < 目标`（接近冷透）→ PI 收阀，温差越小流量越小，不再白排水；
   - 控制器带积分限幅与抗饱和，避免初期满阀时积分堆积、后期关不小。
3. **计量**（`meter.py`）：流量对时间积分得本模用水量（m³）；
   `流量 × ΔT × 水比热` 对时间积分得冷却水带走的热量（kJ），用梯形积分。
4. **冷透判停**（`shot.py`）：`ΔT` 连续低于 `stop_delta_c` 并保持
   `stop_confirm_s`，判定模具冷透，**自动关阀停泵**并出一模报表；
   偶发温度波动不会误停。超过 `max_cool_s` 仍未冷透则发超时告警，
   **保持运行交人工**（不贸然停泵）。

蒸汽联锁维持原设计：整线停运（`stop_cooling`）仍要求先停汽、泄压、排空，
再停冷却；一模结束的自动停泵只是结束本模冷却，回到待机，不排空。

## 关键参数（`config/rubbercure.yaml` 的 `limits.cool`）

```yaml
target_delta_c: 5.0      # 温差目标，℃。大→省水但冷却慢；小→冷却快、用水多
stop_delta_c: 1.5        # 冷透判停温差，℃，必须 < 目标温差
stop_confirm_s: 20.0     # 低温差连续保持多久才停，抗温度抖动
max_cool_s: 1200.0       # 最长冷却时间，超过告警交人工
valve_min_pct: 0.0       # 阀位下限(%)，现场若要求最低流速可设 5~15
min_flow_m3_h: 0.5       # 断流/堵管告警阈值（闭环末段流量本来就低）
```

- **厚模**热负荷大、温差大，阀门会自动开大、冷却时间长；**薄模**很快进入
  收阀阶段。同一套参数自适应，不需要按模具手调。
- PI 增益在 `cool/cool.py` 的 `DEFAULT_DELTA_KP/KI`，现场联调时先保守
  （小 Kp/Ki），观察阀位是否在目标温差附近稳定、不振荡再加大。
- `target_delta_c` 是主要的"省水 ↔ 节拍"旋钮：调大更省水、冷却略慢。

## 每一模的报表

冷却自动结束（或人工提前结束）后得到一条模次记录：

```json
{
  "mold_id": "demo-mold",
  "thickness_mm": 12.0,
  "duration_s": 625.0,
  "water_m3": 2.15,
  "heat_kj": 66292.0,
  "verdict": "cooled",
  "reason": "cooled"
}
```

- `water_m3`：这一模冷却用了多少水（累计流量）；
- `heat_kj`：冷却水这一模带走的热量，可与制品/模具理论放热对比，异常偏低
  说明换热差（结垢、气堵）；
- `verdict`：`cooled`（冷透自动停）/ `timeout`（超时告警）/ `running`；
- 同时发布 `cooling_shot_completed` / `cooling_shot_timeout` 事件，进审计日志。

## 接口

- CLI 演示（无需真机，集总热容仿真厚模/薄模并对比恒流全开）：

  ```bash
  PYTHONPATH=.:vendor python -m rubbercure --config config/rubbercure.yaml cool-demo
  ```

- HTTP：
  - `POST /api/cool-drive` `{ "press_id": "press-01" }`：驱动当前模次冷却到
    冷透停泵（无现场仪表时用内置热模型供水温；真机直接周期喂真实温度即可）；
  - `GET  /api/cool-demo`：厚模/薄模温差调流 vs 恒流全开对比；
  - 状态快照 `GET /api/status` 内的每台机 `cooling` 含阀位、流量、累计水量、
    上一模报表与控制器状态。

真机接入时，把现场 PLC/网关的进出口温度按周期调用
`press.cooling.regulate(inlet_c, outlet_c, dt)`，把返回的 `opening_pct`
写到调节阀即可；模次开始调用 `start_cooling(mold_id, thickness_mm)`，
其余（计量、判停、关阀）自动完成。

## 仿真验证结果（默认参数）

集总热容模型（`cool/simulator.py`），进水 28 ℃、模初温 120 ℃：

| 模具 | 方式 | 冷却时间 | 用水量 | 对比恒流 |
|------|------|----------|--------|----------|
| 薄模 3 mm | 温差调流 | ~195 s | ~0.58 m³ | **省水约 26%**，多 ~40 s |
| 薄模 3 mm | 恒流全开 | ~156 s | 0.78 m³ | — |
| 厚模 12 mm | 温差调流 | ~625 s | ~2.15 m³ | **省水约 24%**，多 ~60 s |
| 厚模 12 mm | 恒流全开 | ~564 s | 2.82 m³ | — |

两副模具都在温差连续低于 1.5 ℃ 后自动关阀停泵，用水量逐模可查。
